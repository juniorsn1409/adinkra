## Como usar

```bash
bun add @adinkra/accordion
```

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@adinkra/accordion";

<Accordion type="single" defaultValue={["envio"]}>
  <AccordionItem value="envio">
    <AccordionTrigger>Quanto tempo leva o envio?</AccordionTrigger>
    <AccordionContent>De 3 a 5 dias úteis.</AccordionContent>
  </AccordionItem>
</Accordion>;
```

Vários itens abertos ao mesmo tempo:

```tsx
<Accordion type="multiple">…</Accordion>
```

Controlado, quando o estado precisa viver fora do componente. O valor é sempre uma lista com os `value` dos itens abertos:

```tsx
const [abertos, setAbertos] = useState<string[]>([]);

<Accordion value={abertos} onValueChange={setAbertos}>…</Accordion>;
```

## Composição

Baseado no [Accordion do Base UI](https://base-ui.com/react/components/accordion), mesma base do `@adinkra/navigation-menu`.

- **`Accordion`** — o cartão que agrupa tudo (borda + sombra dura). `type` decide se abre um item por vez ou vários.
- **`AccordionItem`** — uma seção; `value` a identifica.
- **`AccordionTrigger`** — a linha clicável, já com a seta que gira. Vem dentro de um título (`h3`) para leitores de tela.
- **`AccordionContent`** — o painel que abre e fecha.

## Movimento

O acordeão abre de vez em quando, então vale animar: altura e opacidade em 200ms com `--ease-out`, e a seta gira 180° junto. Altura é a exceção à regra "só `transform`/`opacity`", porque o conteúdo abaixo precisa ceder espaço. A altura vem de `--accordion-panel-height`, que o Base UI mede em pixels (em vez de `interpolate-size`, que ainda não roda em todo navegador). Com movimento reduzido nas preferências do sistema, a troca é instantânea.

## Acessibilidade

Vem do [Base UI](https://base-ui.com/react/components/accordion), seguindo o padrão de accordion da WAI-ARIA APG: cada gatilho é um `<button>` com `aria-expanded` e `aria-controls` dentro de um título. Enter e Espaço abrem/fecham; setas para cima/baixo, Home e End movem o foco entre os gatilhos. Foco visível com o anel padrão do sistema (`--ring`), desenhado por dentro do cartão para não ser cortado.
