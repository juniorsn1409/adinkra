## Como usar

```bash
bun add @adinkra/spinner
```

```tsx
import { Spinner } from "@adinkra/spinner";

<Spinner />;
<Spinner size="lg" label="Carregando relatório" />;
```

Dentro de um botão que dispara uma ação demorada, troque o texto por um verbo no gerúndio ("Salvando…") e desative o botão, como no exemplo acima. Se você sabe quanto falta, use o [Progress](/components/progress); se sabe o formato do que vem, o [Skeleton](/components/skeleton).

## Movimento e acessibilidade

- É um loop funcional, o único movimento contínuo do sistema além do Skeleton. Com `prefers-reduced-motion`, o anel para de girar e pulsa suavemente (2s).
- `role="status"` com o rótulo em texto escondido visualmente — leitores de tela anunciam "Carregando" (ou o seu `label`) quando ele aparece.
- Arco de `--ink` sobre trilha `--hairline`: contraste do arco de 16:1 contra o fundo, bem acima dos 3:1 exigidos.
