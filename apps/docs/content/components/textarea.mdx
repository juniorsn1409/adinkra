## Como usar

```bash
bun add @adinkra/textarea
```

```tsx
import { Textarea } from "@adinkra/textarea";

<Textarea aria-label="Mensagem" placeholder="Como podemos ajudar?" />;
```

O Textarea é só o controle: não traz rótulo, ajuda nem erro próprios (diferente do Input, que embute os três). Para isso, envolva com o `Field` de `@adinkra/field`, que liga `id`, `aria-describedby` e `aria-invalid`:

```tsx
<Field label="Mensagem" error="Escreva ao menos uma frase.">
  <Textarea />
</Field>
```

## Estados

Igual ao Input: borda de tinta + sombra dura sempre, sem o gesto de “pressionar” (digitar não é um clique). O foco usa o mesmo anel de 2px dos botões. A altura mínima é 80px (cerca de 3 linhas) e o campo estica só na vertical, pela alça do canto.

## Acessibilidade

- É um `<textarea>` nativo. Sempre dê um nome: `Field` com `label`, `<label htmlFor>` ou `aria-label`. Placeholder não é rótulo.
- O erro nunca vai só em cor: use o `Field` para o texto que diz como resolver (decisão 6).
- `disabled` tira o campo da ordem de tabulação e desliga o redimensionamento.
