## Como usar

```bash
bun add @adinkra/select
```

```tsx
import { Select, SelectOption } from "@adinkra/select";

<Select label="Fruta" defaultValue="">
  <SelectOption value="">Escolha uma opção</SelectOption>
  <SelectOption value="maca">Maçã</SelectOption>
</Select>;
```

`SelectOption` e `SelectOptGroup` são o `<option>` e o `<optgroup>` nativos, só com as cores do tema (o menu aberto é do navegador).

## Acessibilidade

- É um `<select>` nativo: teclado, leitores de tela e o seletor do celular funcionam sem código extra.
- `label` é ligado ao campo por `htmlFor`/`id`; com `error`, o campo ganha `aria-invalid` e `aria-describedby`.
