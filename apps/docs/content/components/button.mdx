## Como usar

```bash
bun add @adinkra/button
```

```tsx
import { Button } from "@adinkra/button";

<Button variant="primary">Publicar</Button>;
```

## Acessibilidade

- É um `<button>` nativo: funciona com Enter e Espaço, e entra na ordem de tabulação sozinho.
- O anel de foco usa `--ring`, o marinho, com contraste de 12.1:1 sobre o fundo claro (regra S2).
- Desativado, `disabled` também tira o botão da ordem de tabulação — nunca use só uma cor apagada para indicar isso.
