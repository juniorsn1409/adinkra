## Como usar

```bash
bun add @adinkra/navigation-menu
```

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@adinkra/navigation-menu";

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Componentes</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/components/button">Button</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>;
```

## Composição

Baseado no [Navigation Menu do neobrutalism.dev](https://www.neobrutalism.dev/docs/navigation-menu) (mesma base técnica — [Base UI](https://base-ui.com)) — primeira peça do design system a depender de uma lib de UI externa: o posicionamento flutuante entre painéis é complexo demais pra reconstruir do zero, diferente do `@adinkra/sidebar`.

- **`NavigationMenu`** — a raiz; já inclui o `Viewport` (portal + painel flutuante), não precisa declarar à parte.
- **`NavigationMenuList`** — a lista de itens de topo.
- **`NavigationMenuItem`** — um item da lista; pode ser só um link (`NavigationMenuLink` direto) ou ter dropdown (`NavigationMenuTrigger` + `NavigationMenuContent`).
- **`NavigationMenuTrigger`** — abre/fecha o dropdown do item; já vem com a seta que gira.
- **`NavigationMenuContent`** — o conteúdo do dropdown (o que aparece dentro do painel flutuante).
- **`NavigationMenuLink`** — um link, dentro ou fora de um dropdown; `navigationMenuTriggerStyle()` dá a ele a mesma aparência de um `NavigationMenuTrigger`, para item de topo sem dropdown.

## Estados

Vocabulário reaproveitado do resto do sistema, não inventado aqui: hover usa o mesmo `bg-card` do `SidebarMenuButton`; aberto/ativo usa `bg-secondary`/`text-secondary-foreground`, o mesmo "isto está ligado" do `Toggle` e do grupo aberto da `Sidebar` — o céu (`--primary`) fica reservado à ação principal (regra 6, DECISOES.md). Sem borda/sombra no trigger (é navegação, tratamento ghost) — só o painel flutuante leva borda + raio + sombra, como qualquer cartão único do sistema.

## Acessibilidade

Vem do [Base UI](https://base-ui.com/react/components/navigation-menu): navegação por teclado (setas entre itens, Enter/Espaço abre o dropdown, Esc fecha), foco preso dentro do painel aberto, e `aria`s corretos (`aria-expanded`, `aria-current`) geridos pelo primitivo — não reimplementados aqui.
