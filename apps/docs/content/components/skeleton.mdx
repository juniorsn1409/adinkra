## Como usar

```bash
bun add @adinkra/skeleton
```

```tsx
import { Skeleton } from "@adinkra/skeleton";

<Skeleton className="h-4 w-[144px]" />;
```

Não tem variante: forma e tamanho vêm inteiros de `className`, igual à referência do shadcn/ui — um retângulo vira `h-4 w-[144px]`, um avatar vira `h-[42px] w-[42px] rounded-full`.

## Acessibilidade

- Leva `aria-hidden="true"`: é só um efeito visual, não deve ser anunciado por leitor de tela.
- Quem usa o Skeleton é responsável por marcar a região que está carregando com `aria-busy="true"` (ou um `role="status"` com texto tipo "Carregando"), para quem usa leitor de tela saber que algo está em andamento.

## Tokens usados

`--hairline` (preenchimento) — reaproveitado por já ser um neutro decorativo na paleta (regra 3, `DECISOES.md`); a paleta não tem um tom dedicado só para isso.
