## Como usar

```bash
bun add @adinkra/tabs
```

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@adinkra/tabs";

<Tabs defaultValue="conta">
  <TabsList>
    <TabsTrigger value="conta">Conta</TabsTrigger>
    <TabsTrigger value="senha">Senha</TabsTrigger>
  </TabsList>
  <TabsContent value="conta">Dados da conta.</TabsContent>
  <TabsContent value="senha">Troca de senha.</TabsContent>
</Tabs>;
```

Controlado, quando o estado precisa viver fora do componente:

```tsx
const [aba, setAba] = useState("conta");

<Tabs value={aba} onValueChange={setAba}>
  …
</Tabs>;
```

## Composição

Baseado no [Tabs do Base UI](https://base-ui.com/react/components/tabs), mesma base do `@adinkra/navigation-menu`.

- **`Tabs`** — a raiz; guarda qual aba está ativa.
- **`TabsList`** — o trilho que agrupa os gatilhos (borda + `bg-surface`, igual ao NavigationMenu).
- **`TabsTrigger`** — uma aba. Cada `value` casa com o de um `TabsContent`.
- **`TabsContent`** — o painel da aba, mostrado só quando ela está ativa.

## Estados

A aba ativa fica "afundada", a mesma linguagem do `Toggle` ligado e da página atual da `Pagination`: borda de tinta e fundo `--primary`. É indicador de estado, não ação, então repetir a primária é permitido (regra 6). As inativas descansam sem borda e só ganham `bg-card` no hover.

## Movimento

Trocar de aba é navegação frequente, então o conteúdo troca na hora, sem animação. Só a cor da aba transiciona (150ms, `--ease-out`).

## Acessibilidade

Vem do [Base UI](https://base-ui.com/react/components/tabs), seguindo o padrão de tabs da WAI-ARIA APG: `role="tablist"`, `tab` e `tabpanel` ligados por `aria-controls`/`aria-selected`. Tab entra na lista e sai dela; setas (esquerda/direita, ou cima/baixo no vertical) movem entre as abas, Home/End vão às pontas. Foco visível com o anel padrão do sistema (`--ring`).

## Tokens usados

`--ink` · `--surface` · `--card` · `--foreground` · `--primary`/`--primary-foreground` · `--ring` · `--border-width` · `--radius-control`
