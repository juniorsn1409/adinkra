## Como usar

```bash
bun add @adinkra/avatar
```

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@adinkra/avatar";

<Avatar>
  <AvatarImage src="/fotos/ana.jpg" alt="Ana Souza" />
  <AvatarFallback>AS</AvatarFallback>
</Avatar>;
```

O `AvatarFallback` (até duas letras) aparece enquanto a imagem carrega e se ela falhar ou não existir — nunca fica um círculo vazio nem o ícone de imagem quebrada. A `<img>` só entra quando já está pronta.

Um grupo sobreposto, com "+2" no final. Um leitor de tela não sabe contar círculos: dê ao grupo um nome que diga quem são:

```tsx
<AvatarGroup role="group" aria-label="Quem está editando: Ana, Bruno e mais 2 pessoas">
  <Avatar><AvatarFallback>AS</AvatarFallback></Avatar>
  <Avatar><AvatarFallback>BL</AvatarFallback></Avatar>
  <Avatar><AvatarFallback>+2</AvatarFallback></Avatar>
</AvatarGroup>;
```

## Acessibilidade

- A imagem leva `alt` com o nome da pessoa. As iniciais do fallback são texto de verdade, então também são lidas — se o nome já está escrito ao lado, ponha `aria-hidden` no Avatar pra não repetir.
- Iniciais em `--heading` sobre `--surface`: contraste alto nos dois temas.
- Não é interativo e não tem animação. Pra torná-lo clicável, envolva num `<button>` ou `<a>` — o foco visível vem do seu elemento.

## Tokens usados

`--ink` · `--border-width` · `--surface` · `--heading` · `--background`
