## Como usar

```bash
bun add @adinkra/pagination
```

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@adinkra/pagination";

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        1
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">2</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>;
```

Como o `Breadcrumb`, é um conjunto de peças estilizadas, não um componente que sabe paginar sozinho — quem usa decide o `href`/`onClick` de cada link e qual página está ativa (com um router, normalmente a partir da URL).

## Composição

Sete peças, no espírito da [pagination do neobrutalism.dev](https://www.neobrutalism.dev/docs/pagination) (mesma composição do shadcn) — use só as que precisar:

- **`Pagination`** — o `<nav aria-label="pagination">` raiz.
- **`PaginationContent`** — a `<ul>` que encadeia os itens.
- **`PaginationItem`** — um passo da lista (`<li>`).
- **`PaginationLink`** — um número de página (`<a href>`); `isActive` marca a página atual.
- **`PaginationPrevious`** / **`PaginationNext`** — atalhos com seta + texto.
- **`PaginationEllipsis`** — marcador de páginas puladas, para listas longas.

## Página atual

`isActive` deixa o link com a mesma cara "afundada" — borda de tinta, fundo `--primary` (laranja, 17/09 — era `--secondary`), sombra dura — que o `Toggle` usa pro estado ligado. Aqui não é algo que se liga/desliga, é só "você está aqui": sem o convite de hover que os outros números têm.

## Acessibilidade

- `Pagination` é um `<nav aria-label="pagination">` — leitores de tela anunciam a região separada do resto da página.
- `PaginationLink` com `isActive` leva `aria-current="page"` — indica a página atual sem depender só de cor.
- `PaginationPrevious`/`PaginationNext` levam `aria-label` próprio ("Página anterior"/"Próxima página") além do texto visível, então continuam claros mesmo se só o ícone aparecer numa tela estreita.
- `PaginationEllipsis` leva `aria-hidden="true"` — é uma pista visual, a lista de números já basta pra estrutura ser entendida sem ela.
- Sem página anterior/próxima disponível, passe `aria-disabled="true"` em vez de remover o link — ele fica visível, só sai do fluxo de clique/foco (mesmo padrão do `disabled` do Button, mas em cima de um `<a>`, que não tem esse atributo nativo).
