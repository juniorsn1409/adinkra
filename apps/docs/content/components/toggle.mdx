## Como usar

```bash
bun add @adinkra/toggle
```

```tsx
import { Toggle } from "@adinkra/toggle";

<Toggle aria-label="Negrito" defaultPressed>
  <strong>N</strong>
</Toggle>;
```

Controlado, quando o estado precisa viver fora do componente:

```tsx
const [pressed, setPressed] = useState(false);

<Toggle pressed={pressed} onPressedChange={setPressed}>
  Favoritar
</Toggle>;
```

## O gesto persistido

O mesmo "sobe no hover, afunda ao pressionar" do `Button` (seção 4, `DECISOES.md`) — só que aqui o "afundado" não passa quando solta o clique, ele fica enquanto `pressed` for `true`. Desligado, o variant `default` descansa sem borda (como o `ghost` do Button) até o hover convidar ao clique.

## Acessibilidade

- É um `<button aria-pressed>` de verdade — funciona com Enter e Espaço, entra na ordem de tabulação sozinho, e leitores de tela anunciam "pressionado"/"não pressionado" a cada clique.
- Sem texto visível (só um ícone/letra), passe `aria-label` — como no exemplo de Negrito/Itálico/Sublinhado acima.
- `disabled` tira o toggle da ordem de tabulação, igual ao Button.
