## Como usar

```bash
bun add @adinkra/badge
```

```tsx
import { Badge } from "@adinkra/badge";

<Badge>Novo</Badge>;
```

O coral não é uma variante do Badge. No texto pequeno do selo (11px), coral com texto branco dá só 4.2:1 de
contraste — abaixo do mínimo, que só vale a partir de 24px (regra 3, `DECISOES.md`). Por isso essa cor fica de fora
daqui.
