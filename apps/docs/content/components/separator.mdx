## Como usar

```bash
bun add @adinkra/separator
```

```tsx
import { Separator } from "@adinkra/separator";

<Separator />;
<Separator weight="subtle" />;
<div style={{ display: "flex", alignItems: "center", gap: "1rem", height: "1.5rem" }}>
  <span>Componentes</span>
  <Separator orientation="vertical" />
  <span>Tokens</span>
</div>;
```

A vertical não tem altura própria: ela preenche o pai, que precisa ser flex/grid (ou ter altura).

**Decorativo ou semântico?** Por padrão a linha é só visual e some da árvore de acessibilidade (`role="none"`). Passe `decorative={false}` só quando a divisão importa pra quem não vê a tela — por exemplo, entre dois grupos de uma barra de ferramentas.

## Acessibilidade

- Semântico: `role="separator"` + `aria-orientation`. Decorativo: `role="none"`, ignorado por leitores de tela.
- `subtle` usa `--hairline`, que não atinge 3:1 contra o fundo — por isso só serve como enfeite. Se a linha carrega significado, use `solid`.
- Não recebe foco nem interação.

## Tokens usados

`--ink` · `--hairline` · `--border-width`
