## Como usar

```bash
bun add @adinkra/link
```

```tsx
import { Link } from "@adinkra/link";

<Link href="https://exemplo.com">Sponsor</Link>;
<Link href="https://exemplo.com" uppercase={false}>Sponsor</Link>;
```
