## Como usar

```bash
bun add @adinkra/input
```

```tsx
import { Input } from "@adinkra/input";

<Input label="E-mail" placeholder="voce@exemplo.com.br" />;
```

## Acessibilidade

- `label` é sempre ligado ao campo por `htmlFor`/`id` — clicar no texto foca o campo.
- Com `error`, o campo ganha `aria-invalid="true"` e `aria-describedby` apontando para o texto do erro, então leitores de tela o anunciam.
- O `id` é gerado sozinho com `useId()` quando você não passa um — rótulo e campo nunca ficam sem ligação.
