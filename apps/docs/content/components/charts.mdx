## Como usar

```bash
bun add @adinkra/charts
```

```tsx
import { SimpleBarChart } from "@adinkra/charts";

<SimpleBarChart
  data={[
    { month: "Jan", desktop: 186 },
    { month: "Fev", desktop: 305 },
    { month: "Mar", desktop: 237 },
  ]}
  config={{ desktop: { label: "Desktop" } }}
  xAxisKey="month"
/>;
```

`config` é uma entrada por série: a chave bate com uma propriedade de `data`, o valor dá o rótulo (tooltip/legenda) e, opcionalmente, a cor. Sem `color`/`theme` no `config`, a série usa a paleta categórica do próprio sistema (`--tag-coral`, `--tag-sky`, `--tag-mustard`, `--tag-navy` — regra 8, `DECISOES.md`), ciclando pela ordem de declaração das chaves.

## Empilhado com legenda

Uma barra por chave do `config`, empilhadas (`stackId` igual em todas) em vez de lado a lado. Sempre vem com legenda embaixo — a partir de 2 séries, a legenda deixa de ser opcional.

## Valores negativos

Uma série só, cor por sinal: negativo usa `--destructive` (mesma convenção do `@adinkra/data-table`), positivo usa a cor da série no `config`. A `<ReferenceLine y={0}>` marca a linha de base — sem ela, uma barra negativa fica sem referência de onde é zero.

## Sparklines

Linha ou área sozinha, sem eixo/grade/tooltip — pra caber pequena dentro de um KPI ou célula de tabela, sinal de tendência em vez de gráfico de leitura detalhada.

<Preview>
  <div className="grid w-full gap-4">
    <LineSparkline data={[{ v: 10 }, { v: 40 }, { v: 25 }, { v: 60 }, { v: 45 }, { v: 80 }]} dataKey="v" />
    <AreaSparkline data={[{ v: 10 }, { v: 40 }, { v: 25 }, { v: 60 }, { v: 45 }, { v: 80 }]} dataKey="v" />
  </div>
</Preview>

```tsx
import { AreaSparkline, LineSparkline } from "@adinkra/charts";

<LineSparkline data={[{ v: 10 }, { v: 40 }, { v: 25 }]} dataKey="v" />;
<AreaSparkline data={[{ v: 10 }, { v: 40 }, { v: 25 }]} dataKey="v" />;
```

## Tendência de alta e de baixa

Mesma sparkline, cor por convenção: alta usa `--primary` (céu), baixa usa `--destructive` (tomate) — o sistema não tem token verde (decisão revertida, ver `DECISOES.md`/Data Table), então "alta" não vira verde aqui.

## Cor customizada por série

`config` aceita `color` (fixo) ou `theme` (um valor por modo claro/escuro) por chave — sobrescreve a paleta categórica padrão só pra aquela série.

```tsx
<SimpleBarChart
  data={data}
  config={{ desktop: { label: "Desktop", color: "var(--primary)" } }}
  xAxisKey="month"
/>
```

## Tokens usados

`--tag-coral`/`--tag-sky`/`--tag-mustard`/`--tag-navy` (paleta categórica padrão das séries, fatias, blocos e nós) + seus `-foreground` (texto legível dentro dos blocos do Treemap, um par por cor — nunca `--heading` fixo, que falha contraste na mostarda), `--primary` (tendência de alta), `--destructive` (barra negativa, tendência de baixa), `--border` (linha de base do gráfico negativo, guia de hover, ligações do Sankey — nunca `--ink`: essas são linhas de apoio, não dado nem chrome), `--hairline` (grade e linhas de eixo), `--muted-foreground` (texto dos eixos e legenda), `--surface` (fundo do tooltip), `--ink` (só na "cartão" do tooltip — borda/sombra `shadow-brutal`, igual todo painel flutuante do sistema; nenhuma marca de dado usa `--ink`), `--heading` (texto central do donut, rótulos do Sankey fora dos nós).
