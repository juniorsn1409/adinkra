## Como usar

```bash
bun add @adinkra/radio-group
```

```tsx
import { RadioGroup, RadioGroupItem } from "@adinkra/radio-group";

<RadioGroup defaultValue="mensal" aria-label="Plano de cobrança">
  <RadioGroupItem value="mensal" label="Mensal" />
  <RadioGroupItem value="anual" label="Anual" />
</RadioGroup>;
```

Controlado, quando o valor precisa viver fora do componente:

```tsx
const [plano, setPlano] = useState("mensal");

<RadioGroup value={plano} onValueChange={setPlano}>
  {/* ... */}
</RadioGroup>;
```

Para poucas opções que cabem na tela, prefira o RadioGroup ao Select: ninguém precisa abrir nada para ver as escolhas.

## Acessibilidade

- `<div role="radiogroup">` com `<input type="radio">` nativos de mesmo `name`. Por isso o teclado é o do navegador: Tab entra só na opção marcada, as setas movem e marcam (dando a volta no fim), Espaço marca a opção em foco, e opções desativadas são puladas.
- Sempre dê um nome ao grupo: `aria-label`, `aria-labelledby` ou o `Field` com `group`.
- `disabled` no grupo desativa todas as opções; no item, só ela.
- O foco visível é o mesmo anel de 2px dos botões.

## Tokens usados

`--primary` · `--card` · `--ink` · `--border-width` · `--destructive` · `--ring`
