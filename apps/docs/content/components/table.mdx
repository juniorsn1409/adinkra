## Como usar

```bash
bun add @adinkra/table
```

```tsx
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@adinkra/table";

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Título</TableHead>
      <TableHead>Status</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Sankofa e o design de sistemas</TableCell>
      <TableCell>Publicado</TableCell>
    </TableRow>
  </TableBody>
</Table>;
```

## Composição

Sete peças, no espírito do [table do neobrutalism.dev](https://www.neobrutalism.dev/docs/table) (mesma composição do shadcn) — use só as que precisar:

- **`Table`** — o contêiner: borda + sombra dura + cantos arredondados (a mecânica padrão de todo componente único do sistema), com rolagem horizontal própria em telas estreitas.
- **`TableHeader`** / **`TableBody`** / **`TableFooter`**
- **`TableRow`** — uma linha; dentro de `TableBody`, listra sozinha (ver abaixo).
- **`TableHead`** / **`TableCell`**
- **`TableCaption`** — legenda abaixo da tabela.

## Linhas alternadas

`TableRow` listra as linhas pares dentro de `TableBody` automaticamente, com CSS puro (`even:`, o seletor nativo do Tailwind para `nth-child`) — nenhum índice é contado nem passado por prop. O cabeçalho e o rodapé não listram, só o corpo.

## Linhas de grade entre colunas

`columnLines` liga uma borda vertical entre colunas — **ligado por padrão** (a tabela do preview no topo desta página já está com elas). Como as listras, é CSS puro: uma borda à direita em todo `TableHead`/`TableCell` via seletor no próprio `<table>`, removida na última coluna — nenhuma célula precisa saber em qual coluna está. A espessura e a cor são as mesmas do contêiner/header/footer (`--border-width`/`--ink`), não a linha fina entre as linhas (`--hairline`) — é a borda estrutural da tabela, só que na vertical. Desligue com `columnLines={false}` para uma tabela só com as linhas horizontais.

## Acessibilidade

- `Table` renderiza um `<table>` de verdade — leitores de tela anunciam linhas e colunas nativamente, sem precisar de `role` nenhum.
- Use `<TableHead scope="col">` (prop nativa do `<th>`) quando o cabeçalho não for óbvio pelo contexto, para leitores de tela associarem célula e coluna corretamente.
- `TableCaption` é a legenda semântica da tabela — prefira ela a um parágrafo solto acima, porque leitores de tela a anunciam como parte da própria tabela.
