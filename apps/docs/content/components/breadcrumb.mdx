## Como usar

```bash
bun add @adinkra/breadcrumb
```

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@adinkra/breadcrumb";

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Início</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Componentes</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

## Composição

Sete peças, no espírito do [breadcrumb do neobrutalism.dev](https://www.neobrutalism.dev/docs/breadcrumb) (mesma composição do shadcn) — use só as que precisar:

- **`Breadcrumb`** — o `<nav aria-label="breadcrumb">` raiz.
- **`BreadcrumbList`** — a `<ol>` que encadeia os itens.
- **`BreadcrumbItem`** — um passo da trilha (`<li>`).
- **`BreadcrumbLink`** — um passo clicável (`<a href>`).
- **`BreadcrumbPage`** — o passo atual, sem link (`aria-current="page"`).
- **`BreadcrumbSeparator`** — o ícone entre passos; aceita `children` pra trocar o separador padrão (um chevron) por outra coisa, como `/`.
- **`BreadcrumbEllipsis`** — marcador de trilha colapsada, para hierarquias longas.

## Trilha longa (colapsada)

Combine `BreadcrumbEllipsis` com os passos das pontas quando a hierarquia tiver profundidade demais para caber:

## Acessibilidade

- `Breadcrumb` é um `<nav aria-label="breadcrumb">` — leitores de tela anunciam a região como navegação, separada do resto da página.
- `BreadcrumbPage` leva `aria-current="page"`, não é um link — indica o passo atual sem oferecer um clique que não leva a lugar nenhum.
- `BreadcrumbSeparator` e `BreadcrumbEllipsis` levam `aria-hidden="true"`: são pistas visuais, o `<ol>` de `BreadcrumbList` já basta pra estrutura ser entendida sem eles.
