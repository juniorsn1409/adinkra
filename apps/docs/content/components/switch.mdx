## Como usar

```bash
bun add @adinkra/switch
```

```tsx
import { Switch } from "@adinkra/switch";

<div style={{ display: "flex", alignItems: "center", gap: "0.625rem" }}>
  <Switch id="airplane-mode" />
  <label htmlFor="airplane-mode">Modo avião</label>
</div>;
```

Controlado, quando o estado precisa viver fora do componente:

```tsx
const [checked, setChecked] = useState(false);

<Switch checked={checked} onCheckedChange={setChecked} />;
```

## Estados e tamanhos

Ao contrário do Button/Toggle, a trilha não "sobe no hover" — é pequena demais pro gesto, então segue o tratamento mais quieto do Input: borda + sombra dura sempre, só a cor muda. O polegar desliza com `translate-x`.

## Acessibilidade

- É um `<button role="switch" aria-checked>` de verdade, seguindo o padrão de switch da WAI-ARIA APG — não um `<input type="checkbox">` disfarçado. Funciona com Enter e Espaço.
- Sempre associe um `<label htmlFor>` ao `id` do Switch (como nos exemplos acima) — sem isso, quem usa leitor de tela não sabe o que está ligando.
- `disabled` tira o switch da ordem de tabulação.
